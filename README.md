# 이모티미 · EmotiMe

> **내 얼굴로 만드는 3초 이모티콘, 오늘 쓸 답장까지.**
> 사진 한 장 → 아이덴티티 락(Identity Lock) → 24종 표정 뱅크 → 카톡용 팩 · GIF · 실물 굿즈

유료 미니앱(앱인토스 · PWA)으로 출시하는 **개인 사진 기반 이모티콘 제작 서비스**입니다.
기존 레포지토리(v0.1.0, 프롬프트 복사형 제너레이터)는 전면 초기화되었고, 본 저장소는
`이모티미`의 **Step 1 전략/설계 산출물**부터 새로 시작합니다.

## 한 줄 요약

카카오 이모티콘 시장은 **1조 2,000억 원**(누적 매출 1억 원 이상 이모티콘 2,885개)까지 커졌지만,
개인은 여전히 **"그릴 줄 모르면 아무것도 못 만든다"** 는 벽에 막혀 있습니다.
이모티미는 *얼굴 1장 → 검증된 성공 템플릿 → 즉시 카톡 사용 → 실물 굿즈* 로 이 벽을 없애고,
**구독 + 크레딧 + 굿즈 커머스** 3중 수익 구조로 수익화합니다.

## 빠른 시작 (Step 2 이후)

```bash
npm install
cp .env.example .env.local     # 없으면 DEMO_MODE 로 자동 동작
npm run dev                    # http://localhost:3000
```

> Step 1 시점에는 전략/설계 문서만 존재합니다. 코드는 승인 후 생성됩니다.
