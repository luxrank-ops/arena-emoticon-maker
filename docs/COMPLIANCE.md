| 4 | 이용약관 / 개인정보처리방침 | `/terms` `/privacy` |

| 6 | 로그인 필요 서비스 → 심사용 테스트 계정 / 결제 경로 자료 | 시드 계정 + `/api/dev/seed` (운영 비활성) |

> **주의:** 통신판매업 신고번호가 없으면 국민카드 심사에서 제외될 수 있습니다.
> 심사 제출 전 7개 항목을 모두 스크린샷으로 캡처해 제출 자료를 만듭니다.

### 1.3 결제 플로우 (구현 계약)

```
[결제 요청] client → POST /api/checkout { planSku, idempotencyKey }
   → 서버: 금액 서버 산정(클라이언트 금액 신뢰 금지) + 주문 생성(PENDING)
   → 토스 결제위젯 v2 (결제수단: 카드/토스페이/카카오페이)
   → successUrl → POST /api/checkout/confirm { paymentKey, orderId, amount }
   → 서버: 토스 승인 API 호출 → 금액 재검증 → 주문 PAID → 원장 지급(트랜잭션)
[웹훅] POST /api/webhooks/toss  (서명 검증 필수)
   → PAYMENT_STATUS_CHANGED / CANCEL / DEPOSIT_CALLBACK 처리 (멱등)
[정기결제] 빌링키 발급 → 매월 1일 갱신, 실패 시 3회 재시도 → 다운그레이드
```

**필수 안전장치**
- 금액은 **항상 서버**에서 SKU 기준 산정 (위변조 차단)
- 웹훅 서명 검증 + 이벤트 ID 멱등 처리
- 결제 확정과 크레딧 지급은 **같은 트랜잭션** (또는 아웃박스)
- 환불: 관리자 콘솔에서 전액/부분 환불 + 원장 역분개

## 2. 디지털 콘텐츠 청약철회 (전자상거래법 제17조)

디지털 콘텐츠는 **제공이 시작되면 청약철회가 제한**됩니다. 단, 아래 3개를 모두 갖춰야 합니다.

1. **사전 고지** — 결제 화면에서 "생성 시작 시 청약철회 불가" 명시
2. **별도 동의** — 체크박스(필수), 기본값 미체크
3. **증빙 저장** — 동의 시각·IP·약관 버전을 `Order.consentSnapshot`에 저장

**환불 정책 문구(초안)**

| 구분 | 정책 |
| --- | --- |
| 구독 (Plus/Studio) | 결제일로부터 7일 내 **미사용(생성 0컷)** 시 전액 환불. 사용 이력이 있으면 잔여 기간 일할 환불 불가 |
| 크레딧 팩 | 미사용 크레딧에 한해 7일 내 전액 환불. 1컷이라도 사용 시 환불 불가 |
| 굿즈 | 제작 착수 전 취소 무료. 제작 착수 후 단순 변심 불가, **상품 하자 시 교환/환불** |
| 서비스 장애 | 우리 귀책으로 생성 실패한 크레딧은 자동 복구(멱등 롤백) |

## 4. 앱스토어 인앱결제 정책 (래퍼 배포 시)

- iOS/Android 네이티브 래퍼에서 **디지털 재화(구독·크레딧)는 IAP 필수**
- 외부 결제 수단 안내·링크·버튼 **노출 금지** (Apple 3.1.1)
- 구현: 빌드 플래그 `NEXT_PUBLIC_PLATFORM=web|toss|ios|android`
  - `ios|android` → 토스/웹 결제 UI **완전 미노출**, IAP만
- 애플 미니앱 파트너 프로그램(수수료 30%→15%) 적용 가능성 검토

## 5. 개인정보·생체정보 (가장 중요)

### 5.1 분류

| 데이터 | 분류 | 처리 |
| --- | --- | --- |
| 셀피 원본 | **민감정보(생체인식정보) 소지** — 얼굴 이미지 | 별도 동의 / 24h 파기 / 국외이전 고지 |
| 랜드마크 벡터 | 비식별 정보(재식별 불가 수준) | 목적 범위 내 보관 |
| 생성 결과물 | 개인정보(초상) | 사용자 자산, 삭제 요청권 보장 |
| 대화 붙여넣기 텍스트 | 제3자의 대화 포함 가능 | **저장하지 않음**, 요청 처리 후 즉시 폐기 |

### 5.2 동의 UX (3단 분리, 필수/선택 구분)

```
[필수] 서비스 이용약관
[필수] 개인정보 수집·이용 (얼굴 이미지, 목적: 이모티콘 생성, 보유: 생성 후 24시간)
[필수] 개인정보 국외이전 (Google LLC — Gemini API, 생성 목적, 24시간 내 파기)
[선택] 마케팅 정보 수신
```

- 만 14세 미만 가입 차단 (생년월일 또는 본인인증)
- 동의 이력은 `Consent` 테이블에 버전·시각·경로 저장 (철회 시 즉시 반영)

### 5.3 기술적 보호조치

- 전송 TLS 1.3, 저장 시 AES-256 (버킷 기본 암호화)
- 프리사인드 URL TTL 15분, 버킷 수명주기 규칙으로 24h 자동 삭제
- 파기 스케줄러(`purge.worker`) + 파기 로그(누가/언제/무엇을) 보관
- 관리자도 원본 얼굴 열람 불가 (모더레이션은 결과물 기준)
- 접근 로그 90일 보관, 권한은 RBAC(admin/support)

## 6. AI 생성물 표시·딥페이크 대응

| 리스크 | 대응 |
| --- | --- |
| AI 기본법(2026 시행) 생성물 표시 의무 | 결과물 메타데이터 + UI 라벨 "AI 생성" + 내보내기 파일에 `Software=EmotiMe` EXIF |
| 타인 사진 도용 | 셀피 라이브니스(움직임/깜빡임) 요구 + "본인 사진만 업로드" 필수 동의 |
| 유명인·정치인 합성 | 인물 인식 결과 화이트리스트 밖 유사도 높으면 `POLICY_BLOCKED` 반환 |
| 성적/모욕적 합성 | 프롬프트 금지어 + 결과물 NSFW 분류기 2차 검증 |
| 딥페이크 악용 | 워터마크(가시/비가시) + 신고·차단 + 이용약관 금지행위 명시 |
| 저작권(스타일) | 상표명 스타일 사용 금지, 자체 스타일 명칭 6종 |

**약관 금지행위 조항(요지)**
> 회원은 타인의 사진 또는 초상권을 침해할 수 있는 이미지를 업로드할 수 없으며,
> 생성물을 타인을 비방·모욕·협박하거나 허위 사실 유포의 목적으로 사용할 수 없습니다.
> 위반 시 서비스 이용이 즉시 제한되고, 관련 법령에 따른 책임은 회원에게 있습니다.
