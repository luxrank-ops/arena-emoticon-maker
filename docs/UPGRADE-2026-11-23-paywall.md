- 레거시 Plus 크레딧 SKU는 기존 주문 복구용으로만 남기고 화면에서는 숨긴다.

## 2. 무료 미리보기 → 단건 잠금 해제 (페이월)
- 무료 체험은 기존 ‘시안 1장 + 컷 2장’에서 **‘시안 1장 + 12컷 전체 워터마크 미리보기 팩 1개’**로 바뀌었다 (`src/lib/free-trial.ts`, `trial-policy.ts`, `SheetPicker.tsx`).
  - 사용자·IP 하루 1팩, 컷 12장, 이미지 상한(사용자 18 · IP 24 · 전체 45 · 월 900).
  - 미리보기 팩은 크레딧을 쓰지 않는다 (`Pack.preview`).
- 미리보기 렌더는 **저비용 Flash 모델**(`quality: 'preview'`), 잠금 해제 뒤 고화질 재생성은 화풍별 최상위 모델(`finalize`, 추가 차감 없음)로 분리했다.
- `PackViewer`는 결제 전 컷마다 반투명 `이모티학으로 내 얼굴 짤 만들기` 오버레이를 얹고, ZIP·카카오 패키징·고화질 저장을 잠근다. 공유(워터마크 PNG + 초대 링크)는 허용해 바이럴 경로를 남겼다.
- 서버 가드: `packExportState()`가 관리자·검증된 플레이 구매자·유료 등급·`Pack.unlockedAt`만 내보내기를 연다. 주문 API는 팩 소유·잠금 상태·구성별 SKU를 확인하고, 결제 승인 settle 단계에서만 `unlockedAt`을 기록한다. 개편 전에 만든 팩은 잠그지 않는다(2026-11-22 12:00 KST 이전).

## 3. 워터마크 바이럴 · 친구 초대 3컷
- 공유 이미지/문구에 `이모티학으로 내 얼굴 짤 만들기` + `?ref=<코드>` 링크를 넣는다.
- `src/lib/referral.ts`: 초대 코드(8자리) · 방문 시 PENDING 기록 · **초대받은 사람이 첫 미리보기 팩을 만들면 초대한 사람에게 3크레딧(3컷)**. 자기 초대·중복·기존 사용자·하루 5명 상한 방어.
- 팩 화면에 “친구 초대하고 3컷 무료 해제” 카드(링크 복사·초대 실적).
