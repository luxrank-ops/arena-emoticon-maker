# Localization foundation

## Routing and copy

- Korean remains the default at `/` and all existing route paths.
- English uses `/en` and `/en/...`. `src/middleware.ts` rewrites the prefix to the existing page implementation and sets a request-scoped locale header; there is no duplicate route tree to drift apart.
- Server components read `getLocale()` from `src/lib/i18n/server.ts`.
- Shared client/server utilities live in `src/lib/i18n/locale.ts`: `Locale`, `tr`, `localizedPath`, and prefix helpers.
- Use `localizedPath(locale, href)` for internal links. API endpoints and external URLs are not locale-prefixed.
- `LanguageLink` keeps the current pathname when switching languages.

## Presets and generated packs

- Stable expression IDs and visual actions stay language-neutral. Korean and English labels/lines are mapped in `src/lib/i18n/presets.ts`.
- English copy is intentionally written for English chats rather than transliterating Korean memes.
- `POST /api/packs` accepts `locale: 'ko' | 'en'`; `createPack` stores `pack.locale` and writes localized frame labels/lines. Legacy packs without the field are treated as Korean by convention.
- Gemini caption instructions preserve the supplied language, spelling, and punctuation and explicitly prohibit translation. A style name or Korean storefront reference must never change the user's requested caption language.

## Current English coverage

- Localized metadata, `<html lang>`, landing page, shared header/footer, language switcher.
- Upload/photo consent, style selection, character selection, pack creation, pack list, and core pack/download states.
- Natural English comic and photo-sticker presets and localized default pack titles.

## Deliberate follow-up before an overseas release

Authentication, every editor control, payment/billing, support, legal/policy pages, account deletion, moderation, and all API error messages still need complete English/native review. Some English navigation may reach those existing Korean screens while this foundation is reviewed; that is not considered production-ready localization. English Play copy and release blockers are tracked in `docs/STORE-LISTING-EN.md`.

Do not send user photos, private dialogue, or generated email content to localization connectors. Use synthetic glossary/review fixtures only.

## Checks

```bash
npm run test:i18n
npm run test:text-effects
npm run typecheck
npm run build
```

`test:i18n` covers path helpers, all English presets and tones, exact-caption prompts, and file-backed creation of stored English packs. Production payment, Play licensing, native AAB/device behavior, and real Gemini output remain separate release checks.
