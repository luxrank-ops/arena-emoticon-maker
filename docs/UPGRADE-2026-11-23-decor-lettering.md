# 업그레이드 2026-11-23 — 레터링·데코 정갈화 (심플·세련·고급)

사용자 피드백 두 건을 한 번에 반영했다.

> "이모티학 이미지에 생성되는 문양이..좀 조잡 스럽고 수량이 너무많이 생성 되는듯해. 좀더 세련되고 심플 하면서 고급지게 생성되게 해줘"
> "캘리그라피도 정갈 하지 못한것같다. 시인성 좋고 깔끔하고 센스 있고 유행하는 디자인 으로..채택되게 해줘"

## 1. 레터링 (`caption.ts` · `caption-plan.ts` · `layers.ts` · `text-layers-svg.ts`)

- **기본 서체 교체**: Bagel Fat One(EmotiHak Calli) → **주아 Jua**(EmotiHak Round, OFL). 둥글고 또렷해
  카톡 채팅방 크기(약 240px)에서도 1초에 읽힌다. `public/fonts/EmotiHakRound.woff2` 189KB(KS X 1001 + ASCII 서브셋).
- **정갈한 조판**: 줄마다 글자 크기 통일(마지막 줄 확대·강조 단어 확대 제거), 글자별 기울기 3.4° → **0.9°**,
  세로 흔들림 1/3, 자간(주아 +0.004em, 고딕 −0.006em, 굵은체 −0.01em), 행간을 서체 실제 상승부/하강부에 맞춤.
- **시인성**: 흰 스티커 외곽선 **한 겹**(1.15×), 안쪽 톤 링·이중 테두리 제거, 그림자 얕게(0.22/0.05em),
  블록 높이를 실제 글자(상승부 0.80em · 하강부 0.10em)에 맞춰 세로 중심이 정확해짐.
- **회전 절제**: 레이어 회전 저장·UI 범위 ±35° → **±5°**, 새 레이어 기본 0°.

## 2. 데코 (`decor.ts`)

- **수량**: 한 컷 4~5점 → **2~3점**(주 데코 1 + 작은 악센트 1~2). `plain`은 1점.
- **배치**: 사방 흩뿌리기 → **머리 주변 한쪽에만**(정수리/한쪽 정수리 + 같은 쪽 머리 곁, 3점이면 반대쪽 정수리에
  작게). 글자 영역은 비워 시인성을 지킨다. 얼굴 회피·캔버스 클램프는 그대로.
- **컬러**: 원색 34종 팔레트 → **5가지 모던 톤**(샴페인 골드 `#E0B45C` · 로즈 코랄 `#E46B7A` ·
  슬레이트 블루 `#6B87B0` · 라벤더 `#8C7BC8` · 차콜 `#4B5263`)의 **모티프별 한 계열 톤온톤**.
- **도형**: 날렵한 4각 스파클 ✦, 정갈한 하트, 라인 구름, 얇은 물음표·느낌표·음표·왕관·번개 등
  부드러운 베지어로 다듬고 흰 외곽선을 0.24r → **0.16r** 로 얇게.
- **문구 규칙**: 구체적 상황(축하·고마움·칭찬)이 막연한 "진짜"보다 먼저 읽히도록 순서 정리.
