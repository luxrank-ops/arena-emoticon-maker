# 반려동물 누끼 제거 → 원본 배경 + 둥근 사진 프레임 (2026-11-27)

## 계기
사용자 피드백: **"반려동물은 누끼를 안 따는 게 좋아. 털이 있으니깐 누끼가 완벽히 안 따져서 퀄리티가 안 나오네."**
(11-27 오후, `emotihak.com/pets` 실서버 샘플을 보고)

털 끝은 가늘어서 u2net+grabCut 경계가 뭉개지고, 흰 외곽선이 그 지저분한 경계를 그대로 드러냈다.
그래서 **반려동물은 배경을 지우지 않고 사진 그대로 살린 채, 흰 얇은 보더의 둥근 사진 프레임으로 마감**하는 쪽으로 바꿨다.
사람·커플·팀의 누끼(투명 스티커) 기능은 그대로다.

## 바뀐 것

### 1. 실사 샘플 (`public/samples/photo`)
- `pet-dog-sit.webp`(5903 · 턱 괴고 응시), `pet-dog-beg.webp`(5480 · 앞발 내밀며 쳐다보기),
  `pet-dog-look.webp`(3668 · 창가에서 올려다보기): 사용자가 보내 준 시츄 사진에서 강아지 중심으로 타이트하게 크롭
  (사람 발·매트 제외) → 512×512, 투명 바탕 + 부드러운 그림자 + 흰 보더(15px) 둥근 프레임(78px) + 사진 경계 헤어라인.
  대사가 묻히지 않도록 사진 아래 40%에 옅은 그늘(scrim)을 굽고, 대사는 **짙은 잉크(#241C14)** 로 통일.
- `src-dog.webp`(5483): 원본 사진 타일(프레임 없음).
- `/pets` 스트립: 원본 → 오늘 늦게 와?(동글 손글씨) → 지금 뭐 먹어?(예능 밈 굵은체) → 나 좀 봐줘(세련된 캘리그라피).
- README에 제작 방식(누끼 없음 · 프레임 비율)을 갱신.

### 2. 누끼 스튜디오 `/studio/photo`
- **마감 방식** 토글 추가: `✂️ 누끼 (투명)` / `🖼️ 배경 유지 (사진 프레임)`.
- `?subject=pet`(또는 업로드 화면의 반려동물 모드 카드)으로 들어오면 **배경 유지가 기본**으로 켜진다.
- 안내: "털이 있는 반려동물은 배경을 지우면 털 끝이 거칠어져서 이 방식이 더 깔끔해요."
- 배경 유지 모드에서는 외곽선 슬라이더를 숨기고, 미리보기·PNG·GIF·APNG·ZIP이 모두 같은 프레임으로 나간다.

### 3. 내보내기 (`src/lib/export.ts`)
- `ExportOptions.photoFrame` 추가 — 지정하면 누끼·실루엣 외곽선을 쓰지 않고
  흰 보더의 둥근 판 위에 사진을 cover 로 그리고, 대사가 있으면 아래쪽에 옅은 그늘을 깐다.
- 비율 상수 `CUTOUT_PHOTO_FRAME`(`src/lib/studio/photo-cutout.ts`) — 보더 0.03 · 둥글기 0.16 · 여백 0.023.
  샘플 WebP와 앱 결과가 같은 비율이다.

### 4. 반려동물 AI 팩
- `buildPetRenderPrompt` — `photo-sticker` 톤에서는 흰 배경/누끼 지시 대신
  **자연스러운 실내·야외 배경(부드럽게 초점이 빠진)** 을 요구하고, 프레임·테두리·텍스트는 그리지 않게 한다.
  (2D 캐릭터·캐리커처 톤은 기존 누끼 유지)
- `PackViewer` — `subjectKind=pet` + `photo-sticker` 팩은 내보낼 때 `photoFrame` 을 쓴다(외곽선 0).
  팩 화면에 "반려동물 컷은 배경을 지우지 않고 둥근 사진 프레임으로 저장돼요" 안내.

### 5. 문구
- `/pets`: "사진 그대로 누끼 따고" → "누끼 없이 사진 배경 그대로, 둥근 프레임에 집사 밈 대사만",
  FAQ에 "배경을 지우지 않나요?" 추가, `투명 PNG` 표기 → `360×360 PNG`.
- 홈: 히어로 칩 "사진 그대로 → 12컷", 화풍 타일 배지 "무료 · 사진 그대로", 실사 짤 설명에 반려동물 프레임 안내.
