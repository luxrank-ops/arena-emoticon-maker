## 출시 전 반드시 해결
- 실존하는 고객센터 이메일·전화와 사업자 정보를 환경변수에 설정하고 접수·응대 절차를 검증한다. 기존 예시 정보는 실제 접수처가 아니다.
- 법률 전문가 검토 후 상품별 조건·시행일·기존 고객 변경 공지 및 환불 산식의 적용을 확정한다.
- 현재 자동 결제 취소, 구독 해지·정기 결제, 부분 환불, 유료/무료 크레딧의 주문별 소비 귀속 기능은 구현되지 않았다. 운영자가 결제사와 장부를 대조해 처리할 절차를 구축하고 검증한다. 이 초안은 기능 구현을 의미하지 않는다.
- 팩은 컷 수에 해당하는 크레딧을 미리 차감하며 최초 팩의 실패 컷은 자동 복구하지 않는다. 다시 그리기 실패는 자동 복구를 시도하나 저장 실패 시 보장하지 않는다. 실패 컷 및 미사용 잔액 확인·중복 처리 방지를 포함하는 운영 절차가 필요하다.
- 원 결제수단 부분취소, 각 결제사 제한, 환급 시점, 결과물/잔여 권한 처리, 예외 사례와 이의제기 채널을 사전에 점검한다. 사용자에게 비밀번호나 카드 전체 번호를 요청하지 않는다.
