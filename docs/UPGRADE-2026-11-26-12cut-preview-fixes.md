# 업그레이드 2026-11-26 · 12컷 무료 미리보기 표시·재확인 보완

12컷 AI 생성 E2E 실측(2026-11-26, 게스트)에서 확인된 UI·로직 결함 3건을 고쳤다.

## 1. 컷 번호 배지 ↔ `🔒 미리보기` 배지 겹침

- 원인: `PackViewer` 그리드에서 컷 번호 원과 잠금 배지가 **둘 다 `right-2 top-2`** 에 절대 배치돼
  번호(1~12)가 `🔒 미리보기` 를 덮어 `"미리보"` 로 잘려 보였다.
- 수정: 컷 번호를 **좌상단(`left-2 top-2`)** 으로 옮기고, 잠금 배지는 우상단에 그대로 두되
  `whitespace-nowrap` 을 더해 좁은 카드에서도 두 줄로 깨지지 않게 했다.
- 두 배지는 이제 서로 반대 모서리라 카드 폭(모바일 2열 ~ 데스크톱 4열) 어디서도 겹치지 않는다.

## 2. 12컷 팩 제목이 `기본 고빈도 24컷` 으로 표시

- 원인: 무료 12컷 미리보기는 24컷 큐레이션 패키지(`basic-high-frequency`)의 **앞 12컷만** 담는데,
  `createPack` 이 제목을 패키지 기본 제목 그대로 저장했다(내 팩 목록·팩 헤더 모두 이 값을 읽는다).
- 수정: `src/lib/pack-title.ts` 신설.
  - 저장 시점: `createPack` 이 실제 컷 수로 제목을 만든다 → `기본 고빈도 12컷` / `Everyday High-Frequency 12`.
  - 표시 시점: `packDisplayTitle()` 이 내 팩 목록·팩 헤더에서 **이미 저장된 팩도** 실제 컷 수로 보여 준다
    (기존 `pack_mwx2rf9qz8bsss` 처럼 24컷 제목으로 저장된 팩도 새로 만들지 않고 바로 고쳐 보인다).
  - 사용자가 직접 붙인 제목, 컷 수가 같은 정식 24컷 팩, 큐레이션 패키지가 아닌 팩은 건드리지 않는다.

## 3. AI 특징 재확인 실패 → 곧바로 폴백, 컷 이탈

- 원인: `prepareWithFallback` 이 사진 특징 재확인을 **한 번 시도하고 실패하면 즉시** 기본 파일 확인으로
  넘어갔다. 그 상태로 컷을 그리면 인물 일관성이 보장되지 않아 한 컷(7번 "힘내!")의 피부톤·얼굴형이 달라졌다.
- 수정:
  - `prepareWithRetry` — 일시적 장애(`CONSISTENCY_UNAVAILABLE`: 타임아웃·연결 실패·5xx, `CONSISTENCY_QUOTA`: 429)는
    **400ms 뒤 1회 자동 재시도**하고, 두 번째도 실패할 때만 폴백한다.
    사진 자체를 쓸 수 없다는 판정(`PHOTO_NEEDS_REVIEW`)은 결과가 같으므로 재시도하지 않는다.
  - `ConsistencyNotice` — 폴백으로 진행된 경우 미리보기 화면에
    **"닮은 정도가 어색한 컷은 그 컷만 다시 그릴 수 있어요 → 컷 선택 → ‘표정·세부 편집’ → ‘AI로 다시 그리기’"**
    안내를 함께 보여 준다(시트 단계·팩 화면 공통).
