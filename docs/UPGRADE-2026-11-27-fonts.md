## 1) 대사 글자체 4종

| id | 이름 | 번들 폰트 | 성격 |
| --- | --- | --- | --- |
| `round` | 동글 손글씨 (기본) | Jua 주아 (OFL) | 첨부 사진 느낌 — 도톰하고 둥근 손글씨 |
| `brush` | 세련된 캘리그라피 | Dokdo 독도체 (OFL) | 획의 강약이 살아 있는 붓 손멋글씨 |
| `meme` | 예능·밈 굵은체 | Black Han Sans 검은고딕 (OFL) | 자막체, 두꺼운 흰 외곽선 |
| `myeongjo` | 단정 감성 명조 | Gowun Batang Bold 고운바탕 (OFL) | 차분한 인사·감정 컷 |

- `src/lib/studio/caption.ts` 의 **`CAPTION_FACES` 한 곳**에 파일·패밀리·굵기·글자 폭·상승부/하강부·
  시각 크기 보정(`fit`)·자간·외곽선·잉크 살 두께를 모두 모았다. 화면(SVG)과 다운로드(Canvas)가 같은 값을 쓴다.
- 예전 저장값(`calli`·`hand`·`gothic`·`bold`·`stamp`)은 `normalizeTextStyle()` 이 새 4종으로 옮긴다
  (calli·hand → round, brush → brush, gothic·bold → meme, stamp → myeongjo). 이미 만든 팩도 다시 열면 새 서체로 그려진다.
- API(`PATCH /api/frames/:id`)도 예전 값을 받아 저장 전에 정규화한다.

## 3) 품질 개선 (핵심)

1. **서체 보정(`fit`)** — 폰트마다 em 박스 안에서 글자가 차지하는 높이가 달라(붓글씨는 작게, 명조는 크게)
   같은 `size` 에서도 눈에 보이는 크기가 달랐다. `fit` 을 곱해 네 서체의 시각 크기를 맞췄다
   (예: 독도체 ×1.26, 고운바탕 ×0.94).
2. **미리보기 = 다운로드** — SVG 글자를 **한 자씩** 제 위치·각도로 찍는다. 예전에는 런(run) 단위로 찍어
   글자별 자간·기울기가 미리보기에서만 달라 보였다. 칠하는 순서(살 찌우기 → 흰 외곽선 → 채움)도
   캔버스와 같게 맞췄다(이웃 글자 외곽선이 앞 글자 채움을 파고들던 문제).
3. **굵기 불일치 제거** — SVG 는 `font-weight=400` 고정, 캔버스는 서체별 굵기를 써서 브라우저가 합성 굵기를
   더하던 문제. 이제 두 렌더러가 `CAPTION_FACES[face].weight` 한 값을 쓴다(명조는 700).
4. **외곽선 두께 재조정** — 360px 이모티콘에서 흰 외곽선이 얇은 붓획을 먹어 글자가 뭉개졌다.
   서체별로 외곽선은 얇게(붓 0.15 → 0.105), 잉크 살은 두껍게(0.045 → 0.075) 바꿨다.
5. **줄·높이 정리** — 두 줄일 때 블록이 캔버스 아래로 잘리지 않게 `maxHeight`(캔버스 52%)로 한 번 더 줄이고,
   붓 밑줄은 360px 에서 마지막 획과 겹쳐 지저분해 보여 없앴다(여백으로 강약을 살린다).
6. **SVG id 충돌 수정** — 한 화면에 스티커가 여러 개면 `cap0-ink` 같은 그라데이션 id 가 겹쳐
   **모든 대사가 첫 스티커 색으로 칠해지던 버그**. 스티커 스펙 해시로 접두사를 만들어 고쳤다
   (`Sticker` → `renderTextLayersOverlay/renderSticker` 의 `idPrefix`).

## 4) 반려동물 팩

- **대사 인간화(12컷)** — 명령조 키워드 대신 단톡방 말투로:
  지금 뭐 먹어? · 나 좀 봐줘 · 삐졌어 건들지마 · 오늘 늦게 와? · 아 몰라 배째 · 진짜 실화야? ·
  사랑해 집사 · 눈치 챙겨 · 내 말 듣고 있어? · 억울해 죽겠네 · 기분 최고야 · 잘 자요 (영문 12컷 동일).
- **표정·포즈 다양화** — 컷마다 `action` 에 표정·포즈·카메라 각도를 못 박았다(로우앵글·오버헤드·측면·점프 등).
  반려동물 프롬프트에도 "정면 앉은 자세를 기본값으로 두지 말 것"을 명시(`buildPetRenderPrompt`).
- **실사 샘플 교체** — 사용자가 준 시츄 사진으로 `public/samples/photo/pet-dog-{sit,beg,look}.webp`(512, 투명, 흰 외곽선)와
  `src-dog.webp`(원본)를 다시 만들었다(`emotihak-assets/cutout_u2net.py`, u2net + grabCut).
  `/pets` 스트립은 원본 → 오늘 늦게 와?(round) → 나 좀 봐줘(brush) → 지금 뭐 먹어?(meme) 로 보여 준다.
  발·매트가 찍힌 사진은 발이 들어오지 않게 잘라 누끼 떴다.
- `/pets` 문구·`pet-cat-sit.webp`·`src-cat.webp`(미사용) 정리.
