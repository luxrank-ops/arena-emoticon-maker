# 2026-11-24 — 상단 헤더 · 전체 디자인 트렌디 리뉴얼

사용자 지시: "이모티학 앱 이부분(상단 헤더) 디자인을 앱 성격에 맞게 세련되고 트렌디하고 임팩트 있게 바꿔줘. 그리고 전체적인 디자인도 유사 앱들을 참조해서 디자인해줘."

## 1. 문제 (Before)

- 짙은 남색(#1A237E) 2단 헤더 + 시스템 이모지 `🙂` 로고.
- 큰 흰 알약 3개(`EN` / `관리자 | ∞` / `풍고 로그아웃`)가 한 줄을 통째로 차지해 무겁고 촌스러움.
- 본문은 순백 + 남색 대비 → 2026 크리에이티브 스튜디오 앱들과 비교해 "관공서 앱"에 가까운 인상.
- `.eyebrow` 클래스가 여러 화면(`/quotes`, `/presets`, `/studio/photo`, `CurationPackageSection`, `DripThemeSection`)에서 쓰이는데 **정의가 없어** 스타일 없이 렌더되던 결함.

## 3. 디자인 토큰 (tailwind.config.ts · globals.css)

- 팔레트: `cream #FAF8FF`(라벤더 오프화이트) · `ink #17102B`(딥 플럼) · `line #ECE6F7` · `primary #6E29F5`(일렉트릭 바이올렛) · 신규 `hot #FF4D8D` · `apricot #FF9F5A` · `grape #2A1E45`.
- 브랜드 그라데이션: `#7C3AED → #6E29F5 → #A855F7 → #FF4D8D` (`--brand-gradient`, `.brand-gradient`, `.text-gradient`).
- 표면: `.header-surface`(유리 22px blur + saturate), `.header-hairline`(1px 그라데이션 라인), `.mesh-hero`, `.hero-grid`, `.glass`, `.sticker-frame`, `.gradient-ring`.
- 컴포넌트: `.card` 라운드 1.4rem + 라벤더 보더 + 2단 소프트 섀도, `.btn*` **알약형**, `.btn-primary` 그라데이션, `.chip` 유리 칩, `.h1/.h2` 딥 플럼 + 타이트 트래킹, `.eyebrow` 정의 추가.
- `themeColor`/manifest `theme_color`를 `#6E29F5`, `background_color`를 `#FAF8FF`로 갱신.

## 4. 상단 헤더 (SiteHeader · BrandMark · LanguageLink · LogoutButton · SiteNav)

- 1단 슬림 유리 바(모바일 56px / 데스크톱 68px). 스크롤 시 `backdrop-blur` 유리로 콘텐츠가 비친다.
- 브랜드: `🙂` → **커스텀 SVG 심볼**(`BrandMark.tsx`) — 바이올렛→마젠타 스퀴클 + 웃는 얼굴 + 반짝임, 24px에서도 형태가 읽히도록 단순화. 워드마크 `이모티학` + 서브태그 `AI 스티커 스튜디오`.
- 우측: `EN` 미니 토글(28px) · 크레딧 배지(`FREE | ⚡12`, 관리자는 `관리자 | ∞` 그라데이션 원) · 계정 칩(그라데이션 아바타 + 이름 + 로그아웃 아이콘). 데스크톱에만 `만들기` 그라데이션 CTA.
  - 390px 실측: 브랜드 106 + 칩 3개 168 = 여유 있게 1줄.
- 데스크톱 전체 메뉴(PR #109 구조 그대로): 남색 바 → 흰 유리 바 + 알약 세그먼트, 활성 항목만 그라데이션.
- 모바일 상단 보조 탭 줄은 계속 감춤(`hidden … lg:block`) — 하단 `전체메뉴(≡)` 시트가 맡는다.
- 하단 바: 유리 표면 + 활성 아이콘을 그라데이션 원으로. 시트 항목은 `break-keep`으로 한글 음절 중간 줄바꿈 제거.
