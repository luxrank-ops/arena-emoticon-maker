# 이모티학 비용·성능 점검 — 2026-11-24

## 범위와 결론

현재 저장소의 빌드 설정, CI, 정적 리소스, 추천 계산 경로를 점검했다. 사용자 기능·결제·개인정보·크론·배포 설정은 변경하지 않았다. 이 변경만으로 Vercel Hobby 한도 초과를 해결하거나 비용이 특정 금액 줄어든다고 주장할 수 없다.

## 적용

- 추천 팩 구성에서 같은 후보의 동일한 점수를 정렬 비교마다 계산하지 않고 후보당 한 번 계산한다. 셔플과 안정 정렬은 유지한다. 이전 구현과 시간대·팩 크기·최근 사용 내역 60개 조합을 비교하는 테스트를 추가했다. 요청당 CPU 절감은 기대되지만 운영 환경에서 수치로 측정하지 않았다.
- GitHub Actions CI의 `npx prisma generate` 제거. 현재 패키지와 저장소에는 Prisma가 없으며 해당 단계는 오류를 무시하고 있었다. 불필요한 다운로드·실패 가능성을 없앤다. **GitHub Actions에만 적용되며 Vercel 빌드 요금 절감은 아니다.** 향후 Prisma를 도입하면 해당 생성 단계를 복구해야 한다.
- Next.js 16에서 기본 활성화되어 더 이상 유효하지 않은 `experimental.instrumentationHook` 설정을 제거했다. `instrumentation.ts`는 유지하며 빌드 경고만 해소한다.

## 점검 결과와 남은 일

- 사용자가 제공한 현재 Pro 결제 주기 화면에서 이모티콘 앱은 전체 빌드 CPU의 65%, 9시간 28분이다. 이는 당시 Hobby 한도 초과 항목의 증거는 아니며, Vercel의 과거 사용량에서 별도 확인해야 한다.
- GitHub CI와 Smoke는 각각 빌드를 실행한다. 양쪽 목적과 검증을 유지한 채 산출물 공유를 검토할 수 있으나, 이는 Vercel 배포 빌드와 별개다. 이 점검에서는 변경하지 않았다.
- Vercel 자동 배포를 끄거나 특정 변경을 자동 무시하도록 설정하지 않았다. 이전 배포 이후의 누적 변경을 잘못 놓치면 운영 반영이 누락될 위험이 있다. 변경을 모아서 배포하고 불필요한 프리뷰를 줄일 때도 프로덕션과 검증 절차를 유지해야 한다.
- 정적 PNG의 일반 재압축을 시험했으나 픽셀 일치 검증을 통과하지 않아 적용하지 않았다.
- `middleware` 파일 관례 폐기 경고는 남아 있다. 인증 및 라우팅에 영향을 줄 수 있으므로 별도 검증 전에는 변경하지 않았다.
- 현재 앱은 유료 결제 및 사업자 관련 기능을 포함한다. Hobby의 비상업적 사용 조건 적합성을 Vercel에 확인한 후 전환한다.

## 검증

- `npm run typecheck`, `npm test` 통과.
- `DEMO_MODE=1 NEXT_TELEMETRY_DISABLED=1 npm run build` 통과.
- 로컬 데모 서버의 `npm run smoke` 62개 통과. 실제 결제·외부 API·실제 운영 트래픽 및 브라우저/실기기 전체 기능은 검증 범위 밖이다.
- 빌드 시간 비교는 로컬 캐시·환경 영향을 받으므로 절감량으로 사용하지 않는다.
