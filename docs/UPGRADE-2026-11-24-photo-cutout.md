# 업그레이드 2026-11-24 · 내 사진·동영상 바로 누끼 스티커 (움티 지원)

업로드한 **실사 사진 및 1~3초 숏폼 동영상(MP4/MOV/WebM)을 그대로** 스티커로 만드는 흐름을 구축했다.
AI(제미나이)가 사진을 다시 그리지 않고, 기기 안에서 배경만 떼고 캘리그라피 한 줄과 모션을 얹어
**360×360 투명 APNG / GIF / PNG** 또는 **카카오 규격 ZIP**으로 바로 내려받는다.

- 화면: `/studio/photo` (영문 `/en/studio/photo`)
- 진입점: 홈 첫 화면 안내 띠 · `/studio/upload` 표현 형태 화면 상단 카드 · `/quotes` 헤더 보조 버튼
- 비용: 제미나이 호출 없음 → **서버 원가 0원**, 크레딧 차감 없음, 대기 없음
- 개인정보: 사진과 영상은 브라우저 안에서만 처리하고 **서버로 보내지 않는다**(업로드 요청 자체가 없다)

## 주요 기능 및 지원 포맷

1. **단일 사진 + 8종 모션 템플릿**:
   - 정지 컷 외에 8가지 모션(`bounce`, `blink`, `shake`, `sparkle`, `heartbeat`, `float`, `nod`, `swing`) 선택 가능
   - 캔버스 기반 60FPS 실시간 모션 루프 미리보기
   - 단일 다운로드: 360×360 투명 PNG(정지) / 움직이는 GIF(움짤) / 카톡 규격 APNG(무손실 투명)
2. **1~3초 숏폼 동영상 / 연속 컷 누끼**:
   - MP4/MOV/WebM 영상을 기기 안 HTML5 Video + Canvas로 12프레임 균등 추출
   - 각 프레임별 AI 피사체 누끼 + 흰색 스티커 외곽선 + 공통 한글 캘리그라피 자막 합성
   - 질문 예시(getsticker.com '나 지금 가는 중!!')와 같이 실제 인물/반려동물이 자연스럽게 움직이는 실사 카톡 움티 완성
3. **카카오 규격 패키징**:
   - APNG / GIF / PNG 형식별 360×360 규격, 150KB 이하 자동 감색/압축, `validation.json` 동봉 ZIP 다운로드

## 왜 필요했나

PR #104 로 기기 안 AI 피사체 누끼 엔진(`ai-matte.ts`)을 붙였지만, 앱의 모든 내보내기는
**제미나이가 다시 그린 컷**을 대상으로 했다. 사용자가 가진 아기·반려동물·인물 사진을
"AI 재생성 없이 원본 그대로" 스티커로 만드는 길이 없어서, 엔진이 실제 사용자에게 닿지 않았다.
또한 사용자가 원하는 "자연스럽게 살아 움직이는 실사 카톡 움티" 요구에 맞춰 모션 템플릿과 숏폼 비디오 누끼 파이프라인을 연결했다.

## 동작

1. **사진 1~12장** 업로드(끌어다 놓기 · 갤러리 · 카메라). 세로로 긴 사진은 정사각으로 다듬는다
   (얼굴 위주 = 위쪽 32% 기준 / 가운데, 다시 잡기 가능). 800×800 JPEG data URL 로 만들어
   메모리 안에서만 쓴다.
2. **누끼**: `renderFrameCanvas()` 의 기존 하이브리드를 그대로 탄다.
   단색 배경이면 색상 기반(고속), 복잡한 실사 배경이면 사람 `selfie_segmenter` → (피사체가 거의 안 잡히면)
   반려동물·사물 `deeplab_v3` → 둘 다 실패하면 **색상 기반 폴백**. 화면에는 실제 적용 엔진을 한 줄로 보여 준다
   (`✨ AI 정밀 누끼 · 피사체 36%`).
3. **흰 스티커 외곽선** 0~14px (기본 7px, 모든 컷 공통).
4. **캘리그라피 한 줄**: 직접 입력(최대 24자) 또는 **드립·밈 7테마 66줄 원클릭**(`drip-themes` 그대로 재사용).
   서체 5종(라운드 주아 · 붓글씨 · 손글씨 · 고딕 · 굵은체), 위치(아래/위), 글자 크기, 감정 잉크,
   심플 데코(자동/끔), 포인트 이펙트 10종.
5. **내려받기**: 선택 컷 360×360 투명 PNG / 전체 컷 카카오 규격 ZIP
   (`exportKakaoPackZip` → 360×360 · 개당 150KB 자동 압축 · `validation.json` 동봉).

## 화면 설계 메모

- **컷 단위 상태**: 문구·서체·위치·감정·데코는 컷마다 따로 저장된다(다른 컷을 고르면 그 컷의 문구가 나온다).
- **렌더 큐**: MediaPipe 세그멘터는 한 번에 하나만 돌아야 해서 미리보기를 **순차 큐**로 처리한다.
  문구를 타이핑하는 동안에는 240ms 디바운스, 그리는 사이 값이 바뀌면 그 결과는 버리고 최신 값으로 다시 그린다.
- **캐시 키**: `컷 판번호 + 구도 + 스타일 + 외곽선`. 사진 data URL(수백 KB)을 키에 넣지 않아 렌더마다 문자열을 만들지 않는다.
- **ZIP 안내**: 카카오 공식 제안은 32컷이라 1~12컷 팩은 개수 검사에서 실패한다. 내 대화방용으로는 문제가 없으므로
  `validation.exportable`(개수 검사를 뺀 픽셀·용량 기준)로 판정해 "내 대화방에 바로 쓸 수 있어요"로 안내한다.
- 문구 기본값은 글자 크기 0.15 · 아래 위치 0.86 — 두 줄로 접혀도 턱을 덮지 않고 캔버스 밖으로 잘리지 않는 값.
