## 3. 바이럴 엔진 — 0원의 핵심

### 3.1 루프 3개

**루프 ① 결과물 공유 (제품 안에서 끝난다)**

```
팩 완성 → 컷 1장 공유(카톡/링크) → /share/[token] 열람(비로그인)
        → "나도 내 얼굴로 만들기" CTA → 신규 방문 → 가입
```

- 필요한 것: 공유 카드 이미지(4컷 콜라주 + 카피), `/share` 페이지 하단 CTA 강화, UTM `utm_source=kakao&utm_medium=share&utm_campaign=pack_share`.

**루프 ② 초대 보상 (돈 대신 크레딧)**

```
내 초대 링크 → 친구 가입 → 친구 12크레딧 + 나 12크레딧
            → 친구가 팩을 만들면 → 그 친구도 초대 링크를 갖는다
```

- 원가: 크레딧 12개 ≈ 650원(절차적 렌더러 기준 0원, 실 API 기준). **현금 지출 0원.**
- 남용 방지: 동일 기기/번호 1회, 가입 후 24시간 내 사진 업로드 시에만 지급.

**루프 ③ 2인 팩 (커플·팀)**

```
내가 커플 팩 생성 → 상대에게 초대 링크 → 상대 사진 업로드 → 2인 팩 완성
                → 상대도 자기 계정으로 1팩 생성(양쪽 데이터 확보)
```

- 이 루프는 **초대가 필수가 되는 구조**라 K-factor가 가장 높다. W3까지 구현하지 못하면 D+8 이후로 미룬다.

### 3.2 K-factor 계산 — 목표를 숫자로 고정

| 요소 | 현재(추정) | 목표 | 올리는 방법 |
| --- | --- | --- | --- |
| 팩 완성률 | 50% | 55% | 로그인 없는 1컷 체험 → 가입 후 이어서 만들기 |
| 완성자 중 공유율 | 40% | **60%** | 공유 버튼을 결과 화면 상단 고정, 카톡 원터치 |
| 공유 1건당 신규 방문 | 3.0 | 3.5 | 공유 카드에 4컷 콜라주 + 짧은 카피 |
| 방문 → 가입 | 20% | **30%** | `/share` 하단 "내 얼굴로 3분 만에" CTA |
| **K-factor** | **0.12** | **0.30** | 위 4개 곱 |

> K=0.30이면 유입의 30%가 유기적으로 증식한다. K<1이므로 **단독 성장은 불가능**하고, 반드시 채널 유입과 함께 가야 한다.
> 이 사실을 인정하고 "채널 70% + 바이럴 30%"로 자원을 배분한다.

### 4.2 채널별 운영 규칙

## 8. 측정 — 5개 숫자만 본다

### 8.1 퍼널 정의와 목표

| 단계 | 이벤트(PostHog) | 목표 전환 |
| --- | --- | --- |
| 유입 | `$pageview` + UTM | — |
| 사진 업로드 | `photo_analyzed` | 55% |
| 시트 생성 | `sheet_created` | 70% |
| 팩 완성 | `pack_created`(신규 계측) | 55% |
| 공유 | `share_create_landing` | 40% |
| 결제 | `checkout_paid`(신규 계측) | 2.5% |

### 8.2 UTM 규칙 (반드시 통일)

```
utm_source   = instagram | tiktok | blog | blind | everytime | cafe | x
utm_medium   = reels | post | search | dm | seeding | share
utm_campaign = launch1207 | pets | couple | office | xmas | waitlist
utm_content  = 릴스 회차 (r01, r02 …)
```

- 예: `?utm_source=instagram&utm_medium=reels&utm_campaign=pets0912&utm_content=r03`
- 기존 `src/lib/share-attribution.ts` 가 `utm_*` 를 세션에 저장하므로, **공유 링크에도 UTM을 붙이면 2차 유입까지 추적**된다.

### 8.3 주간 리뷰 (월요일 30분)

1. 5개 숫자 기록(가입·업로드·완성·공유·결제) → 전주 대비.
2. 콘텐츠 상위 1편 / 하위 3편 확인 → 하위는 왜 안 됐는지 한 줄.
3. 다음 주 **실험 1개만** 정한다(예: "훅을 결과물 먼저 vs 사진 먼저").
4. 실험 결과는 `docs/MARKETING-LOG.md`(신규)에 3줄로 남긴다.
