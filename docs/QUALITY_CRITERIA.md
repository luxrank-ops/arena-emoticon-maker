# EmotiMe 유료화 품질 기준 (QUALITY CRITERIA)

## 목적
유료 구독·크레딧 모델을 도입하기 전, 사용자가 지불할 만한 생성 품질 기준을 정의한다.

---

## 1. 품질 목표 (정량 지표)

| 지표 | 목표 값 | 측정 방법 |
|------|---------|-----------|
| 얼굴 닮음도 (Identity Score) | 5점 척도 3.8↑ | 내부 평가단 블라인드 테스트 |
| 동일 인물 일관성 (다양 표정/포즈) | 5점 척도 4.0↑ | 동일 사용자 6컷 생성 시 얼굴 구조 일치도 |
| 스타일 일관성 (톤별) | 5점 척도 4.0↑ | 동일 톤(2D 귀여움·3D 카툰 등) 생성물 간 화풍 통일도 |
| 생성 성공률 | 95%↑ | API 호출 중 유효 이미지 반환 비율 |
| 평균 생성 시간 | 30초 이하 | 사용자 셀피 업로드 → 결과물 표시까지 |
| 해상도 | 2048×2048 px 이상 | 인쇄·굿즈 제작 가능 해상도 |

---

## 2. 품질 평가 항목 (정성)

### 2.1 정체성 보존 (Identity Lock)
- 동일 사용자가 다른 감정(기쁨·슬픔·놀람 등)으로 생성해도 **같은 사람**으로 인식되어야 함
- 헤어스타일, 얼굴 윤곽, 눈·코·입 비율이 원본 사진과 유사해야 함
- 안경 착용 여부, 피부톤이 원본과 일치해야 함

### 2.2 스타일 일관성
- 선택한 톤(2D 귀여움, 3D 카툰, 캐리커처 등)에 맞게 선 두께·채도·그림자가 통일되어야 함
- 카카오톡 이모티콘 규격(정사각형, 말풍선 포함)에 맞게 레이아웃이 잡혀야 함

### 2.3 사용성
- 업로드 후 30초 이내 결과물 표시
- 재생성 요청 시 이전 결과와 다른 변형 제공 (시드 다양성)
- 모바일 브라우저에서 카메라·갤러리 업로드 모두 정상 동작

---

## 3. 게이트 (릴리스 전 필수 통과 항목)

- [ ] MediaPipe FaceLandmarker 도입 완료 (랜드마크 기반 얼굴 분석)
- [ ] AI 이미지 생성 API 연동 (Stable Diffusion XL / Gemini 2.5 Flash Image 등)
- [ ] 스타일 LoRA 3종 이상 학습 완료 (2D 귀여움, 3D 카툰, 캐리커처)
- [ ] 내부 평가단 10명 이상 얼굴 닮음도 평균 3.8↑ 검증
- [ ] 생성 성공률 95%↑, 평균 생성 시간 30초 이하 측정 완료
- [ ] NSFW·유명인 얼굴 필터 적용 (안전장치)
- [ ] 크레딧 차감·환불 정책 연동 완료
