# 구독 및 굿즈 구현 진행 상태

두 상품 모두 판매 준비 중이며 실제 판매를 활성화하면 안 됩니다.

- 구독: 토스 빌링키 발급·암호화 보관, 최초 및 정기 승인, 중복 방지·실패 복구, 해지, 스케줄러, 승인된 주기에만 혜택을 부여하는 처리와 검증이 필요합니다. 현재 차단을 유지합니다.
- 굿즈: 서버 소유권·가격 확인, 주문 이미지 스냅샷, PENDING 결제와 승인 후 접수 상태를 위한 코드가 진행 중입니다. 이행 관리자 화면 및 보호된 원본 접근, 배송 상태 처리, 보관·삭제 정책, 결제 실패 복구와 회귀 테스트가 아직 필요합니다. `goodsFulfillmentReady`는 항상 false이며 환경 변수로도 판매를 열 수 없습니다.
- 실제 활성화 전 토스 계약과 실키, 제작·배송 공급 및 가격·환불 정책, 영속 스토리지, 운영 절차와 실환경 검증이 필요합니다. 모의 승인이나 주문 접수를 실제 제작·배송으로 오인해서는 안 됩니다.
