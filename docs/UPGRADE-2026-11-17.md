## 1. 움직이는 이모티콘

- `src/lib/studio/motion.ts` — 8개 모션 템플릿(바운스·깜빡임·흔들림·반짝이·두근거림·둥실둥실·끄덕끄덕·좌우 스윙). 위치/크기/회전/투명도와 파티클을 t(0~1)의 순수 함수로 계산해 미리보기와 내보내기가 완전히 같은 그림을 만든다.
- `src/lib/studio/apng.ts` — 외부 의존성 없는 APNG 조립기. 프레임별 `canvas.toBlob('image/png')` 결과의 IHDR/IDAT 청크를 그대로 옮기고 `acTL`·`fcTL`·`fdAT`만 덧붙인다(재압축 없음, CRC32 자체 구현).
- `renderAnimatedGifBlob` — gifenc 로 GIF(투명 인덱스 계산, `dispose: 2`) 생성.
- `FrameEffectsPanel` — 모션 선택 시 `requestAnimationFrame` 으로 바로 움직이는 미리보기, 1회 재생 시간·프레임 수 표시, GIF/APNG/PNG 내보내기.
- AI API 추가 호출은 0회다(전부 브라우저 Canvas).

## 2. 고정밀 누끼 · 흰 외곽선 · 카톡 규격 패키징

- `computeAlphaMask` — 가장자리에서 4방향으로 이어진 밝은 무채색만 배경으로 판정(눈동자·옷 안쪽 흰색은 보존). 배경에서의 BFS 거리로 `feather` px 알파 램프를 만든다.
- `applyMask` — 반투명 경계의 흰색 번짐(halo)을 알파로 나눠 되돌린다(decontamination).
- `applyWhiteOutline` / `outlineSilhouette` — 불투명 영역의 알파를 바깥으로 확장해 흰 스티커 테두리를 그림 뒤에 깐다(두께 0~12px, UI 슬라이더).
- `compressPngUnderLimit` — 150KB 를 넘으면 색 단계(64→4)와 알파 단계를 낮춰 다시 인코딩하며 목표에 가장 가까운 결과를 고른다.
- `KAKAO_RULES` 를 2026년 기준(32종 · 360×360 · 개당 150KB · 아이콘 16KB)으로 갱신하고 `KAKAO_ANIMATED_RULES`(APNG/GIF · 2MB)를 추가. 개수 미달은 차단하지 않고 안내만 하며, 픽셀·용량 위반은 차단한다.
- `exportKakaoPackZip(items, { outline, motion, animationFormat })` — 정지 PNG / 애니메이션 APNG·GIF 를 골라 한 번에 ZIP + `validation.json`.

## 3. 고정 캐릭터 디자인 시트

- `buildCharacterSheet()` 가 화풍·대상·구도·팔레트·얼굴 시그니처로 **결정적 id** 를 가진 시트를 만든다(의상·헤어·비율·구도·금지 규칙).
- `designSheetPrompt()` 잠금 블록을 모든 컷 프롬프트에 넣는다(`gemini-render`, `generate/batch` 공통).
- 팩 생성 시 `pack.designSheet` 로 고정되고, 컷 생성 시 사진 + 선택한 시안 + 디자인 시트가 함께 전달된다. 팩 화면에서 고정 항목을 확인할 수 있다.

## 4. 한글 대사·효과음 레이어

- `RenderInput.textMode = 'layer'` 이면 프롬프트가 글자를 전면 금지하고("No lettering at all"), 앱이 `TextLayer` 를 합성한다.
- 레이어: 손글씨/고딕/굵은체/도장 × 말풍선(둥근·삐죽·자막 바·테이프) × 이펙트(땀·하트·반짝이·분노·돈·불꽃), 위치·크기·회전·색 편집.
- `PATCH /api/frames/[id]` 로 프레임에 저장되고 `spec.textLayers` 를 통해 PNG·GIF·APNG·ZIP 모든 내보내기에 자동 반영된다.

## 5. 표현 형태 5종

| id | 이름 | 컷 | 특징 |
| --- | --- | --- | --- |
| `situation` | 상황·행동 리액션 | 24 | 퇴근·커피 수혈·확인했습니다·지금 출발·야근 중 등 |
| `parody` | 짤·뉴스·자막 패러디 | 24 | 극단 줌인 정색, `[속보] 오늘 야근 확정` 자막 바 기본 레이어 |
| `duo` | 2인·반려 케미 | 24 | **사진 2장 업로드**, 하이파이브·삐짐·어깨동무 등 2인 구도 |
| `typo` | 글자 주인공(타이포) | 24 | 캐릭터는 구석에 작게, 도장·손글씨가 주인공 |
| `combo` | 이펙트·2단 합체 | 24(12쌍) | 불꽃·돈다발·하트 폭격 + 위아래가 이어지는 콤보, 합체 미리보기 |

- 선택 UI: `/studio/upload` 1단계(`PackFormatPicker`) → `/api/sheets` → `/api/packs` → `/api/render` 까지 `format` 이 전달된다.
- 2인 팩: 두 번째 사진을 별도 스코프(`duo:<id>`)로 보관하고, `/api/render` 가 `secondPhoto` + `secondConsistency`(사전 확인 토큰)를 검증한 뒤 두 장을 레퍼런스로 넣는다.
- 콤보: 위/아래 컷에 `comboRole`·`comboPairId` 를 저장하고, 팩 화면에서 짝을 합친 2단 미리보기를 PNG 로 저장한다.

## 안전·운영 가드 (변경 없음)

- `GENERATION_ADMIN_ONLY` 기본값 `1`, `PLAY_BILLING_ENABLED` 기본값 `0`, `ADMIN_LOGIN_ANY_IDENTIFIER` fail-closed 유지.
- 원본 사진은 여전히 서버에 저장하지 않는다(요청 본문으로만 전달, 두 번째 사진 포함).
- AI 생성은 여전히 `canUseAiGeneration` 게이트를 통과해야 한다.
